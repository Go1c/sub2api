# 管理员设置保存幂等性

`PUT /api/v1/admin/settings` 现在带有服务端隐式幂等保护：

- 服务端按 `管理员 ID + 请求 body` 生成幂等键。
- 同一管理员在 60 秒内重复提交同一设置 body 时，只执行第一次写入。
- 后续重复请求直接复用第一次成功响应，并返回 `X-Idempotency-Replayed: true`。
- 如果第一次请求仍在处理中，重复请求会收到现有幂等协调器的处理中冲突响应。

前端设置页也会在保存请求进行中阻止再次提交，并保持保存按钮禁用到响应结束。服务端幂等仍是最终防线，用于覆盖网络重试、浏览器重复提交或客户端状态更新延迟。
