# LumioAPI 订阅计价计算器

简介：一套本地离线的订阅套餐计价工具，用于按「实际到账金额」反推可用额度、套餐折扣、实际单价以及日/周消耗上限。不依赖 `frontend/`、`backend/` 或构建流程，浏览器打开即用。

## 背景 / 目标

为订阅套餐定价提供统一计算口径，便于在文档、表格或后台配置讨论稿中快速核对折扣与额度。本地工具路径：

```text
tools/subscription-pricing-calculator.html
```

直接用浏览器打开即可使用。

## 设计

### 计算口径

默认普通充值基准：

```text
1 刀 = ¥0.35
```

在每个套餐里填写「实际到账金额」，工具自动计算：

```text
可用额度       = floor(实际到账金额 / 普通充值基准)
套餐折扣       = 套餐价格 / 实际到账金额
实际单价       = 套餐价格 / 可用额度
日上限真实金额 = 日上限 * 普通充值基准
周上限真实金额 = 周上限 * 普通充值基准
```

### 日/周上限策略

日上限和周上限按套餐定位自动计算：

| 套餐 | 策略 |
|------|------|
| 轻享版 | 性价比入口，卡紧日限和周限 |
| 标准版 | 主推跑量，适当限制周消耗 |
| 专业版 | 高频用户，放宽日限和周限 |
| 团队版 | 最优单价，高消耗团队档 |

限制值按最终推荐版的日/周比例随可用额度联动，并按配置友好的整数做四舍五入。

### 默认价格

| 套餐 | 套餐价格 | 默认实际到账金额 | 默认可用额度 | 默认日上限 | 默认周上限 |
|------|----------|------------------|--------------|------------|------------|
| 轻享版 | ¥79/月 | ¥93 | 265 刀 | 21 刀 | 70 刀 |
| 标准版 | ¥199/月 | ¥240 | 685 刀 | 85 刀 | 230 刀 |
| 专业版 | ¥399/月 | ¥488 | 1394 刀 | 230 刀 | 600 刀 |
| 团队版 | ¥799/月 | ¥999 | 2854 刀 | 520 刀 | 1300 刀 |

## 已决策

- 折扣目标建议保持在 `8.0 折 - 8.5 折`。
- 日上限和周上限只限制套餐额度；超过后仍可继续使用普通余额。
- 工具完全离线，不接入构建流程，避免增加 upstream 同步负担。
